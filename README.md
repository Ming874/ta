# 聖心醫院 · 殭屍生存

網頁 3D 第一人稱殭屍生存射擊遊戲(Three.js r186 + Vite 8)。
午夜之後的聖心醫院:地下納骨堂、挑高大廳、重複得令人迷失的病房、精神科隔離區與醫院外的停車場與墓園。撐過一波又一波的屍潮,在回合之間到 1F 便利商店改成的商店補給、升級武器。支援 2–4 人合作生存與 2–8 人對戰死鬥連線。

## 特色

- **多樓層醫院**:B1 / 1F / 2F / 3F 加上戶外區域,約 75 個風格不同的區域;燈光、霧與環境音依區域變化,有腳本化的心理驚嚇事件。
- **五種殭屍**:行屍、狂奔者(飛撲)、爬行者、膿腫者(吐酸、死亡爆炸)、巨屍(衝鋒、穿護甲)。可斷頭斷肢,死後變成物理布娃娃。
- **六把武器**:手槍、左輪、霰彈槍、AK-47、M4A1、巴雷特(全螢幕狙擊鏡);另有手榴彈與小刀。開鏡、後座圖樣、穿透與距離衰減。
- **回合制難度曲線**:每 5 回合首領回合(巨屍),第 8、13、18… 回合是特殊回合(狂奔之夜 / 膿毒潮);第 5 回合起殭屍血量逐步增加。
- **商店**:武器、各武器彈藥(買不起補滿時可只買幾個彈匣)、四種改裝(傷害 I–III、彈匣 I–II、換彈 I–II、穩定 I–II,價格逐級遞增)、防彈背心與修補、手榴彈、醫療包、急救處置。數值條會與手上的武器比較。
- **掉落物**:殭屍會掉落彈匣與醫療包(偶爾手榴彈),會發光、靠近自動吸過來,約 40 秒後閃爍消失;彈藥或生命不足時掉落率提高。
- **計分與紀錄**:爆頭、近戰、連殺倍率、無傷清場;死亡結算顯示各類型擊殺、爆頭率、命中率、最高連殺,並保存本機最佳紀錄。
- **新手提示**:依情境出現一次的提示(按 T 關閉,可在設定重設)。
- **設定**:滑鼠靈敏度、反轉 Y 軸、FOV(開鏡與狙擊鏡跟著縮放)、主音量/音樂/音效、畫質預設(依顯示卡自動挑選)、陰影、光暈、動態解析度。
- **效能**:Web Worker 建模與貼圖、Rapier 物理(WASM)、固定光源池、動態解析度;按 F3 看效能面板。可安裝為 PWA。

## 遊戲規則

- 每回合清光殭屍後,地上的金幣(以及用得到的掉落物)會飛向你,並發放清場獎勵(20 + 10 × 回合);整回合沒受傷再加「毫髮無傷」獎勵。
- 回合間休息 30 秒(首領回合前 40 秒),商店捲門拉起;**單人模式購物時遊戲暫停**。每回合開始每把武器自動補 2 個彈匣,回合結束回復 20 生命。
- 金幣:行屍 6、狂奔者 8、爬行者 7、膿腫者 12、巨屍 45;爆頭 +50%、近戰擊殺 +100%;5、8、12、16、20 連殺另有金幣獎勵。
- 武器價格依實測經濟設定(第 1~6 回合每回合收入約 84 / 126 / 165 / 233 / 338 / 435):左輪 120、霰彈槍 180、AK-47 300、M4A1 450、巴雷特 650。
- 數值集中在:`src/weapons/weapon.js`(武器)、`src/game/waves.js`(回合數量/組成/血量倍率/節奏、計分、獎勵)、`src/shop.js`(商品與價格)、`src/pickups.js`(掉落率)、`src/zombies/types.js`(殭屍基本數值)。

## 執行與建置

需要 Node.js 20 以上。

```bash
npm install
npm run dev          # 開發伺服器 http://localhost:5173(單人可直接玩)
npm run server       # 另開一個終端機:多人連線伺服器(預設 8787),開發伺服器會把 /ws 轉過去
npm run build        # 輸出到 dist/
npm start            # 正式環境:node server/index.js 同時提供 dist/ 靜態檔與 /ws(使用 PORT 環境變數)
```

- 正式伺服器會送出跨來源隔離標頭(COOP / COEP),讓物理 Worker 可以使用 SharedArrayBuffer;開發伺服器(vite.config.js)也一樣。
- 健康檢查:`/healthz`;公開房間列表:`/api/rooms`。
- 網址參數(除錯用):`?physics=off|main|worker`、`?blockout`(灰盒場景)、`?room=代碼`(直接加入房間)。

### 部署(Zeabur)

`zbpack.json` 已設定 `build_command: npm run build`、`start_command: node server/index.js`;平台提供的 `PORT` 會自動使用。推送到追蹤的分支即會重新部署。

## 多人連線

主選單選「合作生存」或「對戰死鬥」進入大廳:設定暱稱、建立房間(公開或私人)、輸入 6 碼代碼加入,或從公開房間列表加入;房間內可以聊天、準備、由房主開始。邀請連結為 `?room=代碼`。

- **合作生存**(2–4 人):共用殭屍與回合;血量歸零先倒地 30 秒,隊友靠近按住 E 3 秒救起;全員倒地才結束。
- **對戰死鬥**(2–8 人):各自為戰,先到擊殺上限或時間到結束,可選擇加入零星殭屍騷擾。
- 由房主的瀏覽器模擬殭屍與回合,伺服器只負責房間與轉發;房主離線時自動轉移。

## 專案結構

```
src/main.js            啟動、主迴圈、PWA
src/game.js            Game:渲染器、場景、各系統
src/game/              flow(回合/商店/計分)、waves(難度曲線)、combat(射擊/爆炸)、input、fx、post
src/map/               多樓層佈局(levels.js)、碰撞與導航、醫院建構、室內/戶外道具
src/zombies/           殭屍類型、AI、程式生成模型(Worker)
src/weapons/           武器數值與系統、模型、彈道、特效、狙擊鏡
src/shop.js            商品目錄、購買邏輯、商店店面
src/pickups.js         掉落物與補給櫃
src/ui/                HUD、商店介面、地圖、選單與設定、新手提示
src/audio/             WebAudio 即時合成的音效與配樂
src/physics/           Rapier 物理(布娃娃、動態道具)
src/net/               多人連線(大廳、同步、合作/對戰)
src/sys/               Worker 池、畫質管理、效能面板
server/index.js        靜態檔 + WebSocket 房間伺服器
public/                貼圖、模型、圖示、Service Worker、授權署名
```
