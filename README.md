# 廢棄醫院 · 殭屍生存 (FPS)

Three.js + Vite 的第一人稱寫實風殭屍遊戲。場景是破爛的醫院,撐過一回合又一回合。

## 執行
```
npm install
npm run dev      # http://localhost:5173
npm run build
```

## 操作
| 按鍵 | 功能 |
|---|---|
| WASD / Shift | 移動 / 奔跑(奔跑時不能開槍) |
| 滑鼠左鍵 / R | 射擊 / 換彈 |
| 1-4 或滾輪 | 切換武器(手槍/左輪/AK-47/M4A1) |
| F | 手電筒 |
| E | 在商店旁開啟商店 |
| N | 商店階段/休息時立即開始下一回合 |

## 規則
- 頭頂血條依剩餘比例變色:滿血綠 → 2/3 橘 → 1/3 紅(中間漸變);爆頭 2 倍傷害。
- 殭屍死亡掉金幣(依類型 5–25 枚),疊在同一個地方;**回合結束時所有金幣自動飛進你的庫存**。
- 每 **5 回合**結束,醫院大門(南側玄關)出現商店:左輪 100、AK-47 250、M4A1 400、彈藥補給 100(已擁有的槍補彈半價)。
- 起始武器為手槍;每回合結束回 25 血,每回合開始補給彈藥。

## 殭屍類型
第 1 回合只有行屍,之後依序加入新類型(首次出現的回合保證至少一隻)。

| 類型 | 出現 | 血量 | 特徵與行為 | 金幣 |
|---|---|---|---|---|
| 行屍 | 第 1 回合起 | 150 | 病人袍/醫師白袍/刷手服/清潔工/便服;有的雙手前伸、有的單手、有的垂手;部分跛腳拖步,會不定時踉蹌;抓住後咬 | 5 |
| 狂奔者 | 第 2 回合起 | 90 | 衝刺速度接近玩家奔跑;發現玩家會尖嘯,之字形逼近,2–4 m 內蹲低後飛撲;腿部中彈會摔倒滑行再爬起 | 6 |
| 爬行者 | 第 3 回合起 | 80 | 下半身斷裂(拖著內臟)或雙腿殘廢,趴地用雙手交替拖行,目標低、難瞄準;靠近時撐起身抓咬 | 5 |
| 膿腫者 | 第 4 回合起 | 220 | 腹部脹大、全身發光膿包;中距離後仰蓄力吐出拋物線酸液,落地形成酸池持續傷害;死亡時膨脹爆開,炸傷周圍玩家與殭屍並留下毒氣 | 8 |
| 巨屍 | 第 5 回合起(每 5 回合多一隻) | 900 起 | 2.2 m 高、穿戰術背心(打身體只有 55% 傷害);重踏震動鏡頭,咆哮後直線衝鋒(撞到玩家會擊退),撞牆會暈眩且受傷 1.6 倍;近身雙拳重砸 | 25 |

- 模型全部程式生成:以骨架蒙皮的單一網格(關節平滑變形、下顎可張合),雕塑頭部(眼窩、鼻樑、顴骨、牙齒、混濁眼球)、可破損的布料(毛邊、破洞露出皮膚)、頂點繪製的屍斑、瘀青、血管、咬傷/撕裂傷/外露肋骨、流下的血。每種類型預先生成數個變體(身材、膚色、髮型、服裝、傷口各不相同)。
- 射擊判定用掛在骨骼上的隱形命中盒,分為頭、身體、護甲、手、腿。

## 音效與配樂
全部以 WebAudio 即時合成:分層槍聲與換彈步驟、3D 定位的殭屍叫聲(每種類型聲紋不同)、會隨威脅距離與巨屍出現而變化的恐怖配樂、醫院環境音、低血量心跳。

## 武器模型
預設為程式生成的細緻模型(擠出輪廓、倒角、車削槍管、可動滑套/槍機/彈巢/彈匣),配色依真槍(AK-47 胡桃木+磷化黑鋼、M4A1 黑色陽極、Colt Python 藍鋼+木握把、Glock 黑色聚合物)。
想換成網路上的擬真模型:把 GLB 放進 `public/models/`,檔名 `pistol.glb`、`revolver.glb`、`ak47.glb`、`m4a1.glb`,
遊戲會自動載入並縮放到真槍長度(槍管需朝 -Z 或 X 軸;握把位置可在 `src/weapons/models.js` 的 `tryLoadGLB` 微調)。
請確認模型授權(建議 CC0)。

## 數值調整
武器數值集中在 `src/weapons/weapon.js` 的 `WEAPONS`;殭屍各類型的血量、速度、攻擊與每回合出怪組成在 `src/zombies/types.js`。
